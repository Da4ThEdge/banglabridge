## BanglaBridge

A simple voice-note Flutter app, to demonstrate on-device, offline Bengali Speech Transcription using Silero VAD + a finetuned and quantized Whisper-Base model.

Whisper-Base model here is INT8 quantized and CPU optimized using the [Microsoft's Olive Toolchain](https://github.com/microsoft/Olive/tree/6ab9d8bb9284a89ccc87c63ca323c0f3386f6426).

⚠️ Dependency: To run the project you must need this modified version of the [FONNX Package](https://github.com/Telosnex/fonnx), placed at the same directory level as this project.

🏆 This was one of the 15 shortlisted Capstone Projects at the [Innovation Challenge, Season 16](https://www.facebook.com/share/p/15paCsptVY/) (Spring 2025), hosted by NSU ACM Student Chapter, North South University, Dhaka, Bangladesh.
